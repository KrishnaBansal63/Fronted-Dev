3. Describe how a browser requests and displays a web page from a web server.

#The user enters a URL or clicks a link.

#The browser resolves the domain to an IP address using DNS.

#It establishes a TCP connection with the server.

#The browser sends an HTTP request (like GET).

#The server processes this request, possibly querying a database.

#The server returns content (HTML, CSS, JS, images, etc.).

#The browser receives, parses, and renders the web page for the user
