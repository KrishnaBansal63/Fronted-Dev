Hover to change background; focus shows outline; active simulates press.

Explanation:

:hover — used to change visual state when the pointer hovers over an element.

:focus — indicates element has keyboard focus (useful for accessibility).

:active — applied while the element is being activated (pressed).

Buttons
Hover to darken; focus shows outline ring; active moves the button down slightly.

Explanation:

Buttons commonly use :hover, :focus and :active to give tactile feedback.

Use :focus-visible to target keyboard focus specifically for better UX.
